# Feri

Feri is a B2B FMCG ecommerce prototype for kirana stores, small retailers, offices, and resellers.

## What is included

- FMCG product catalog with categories
- Offer banners and margin-led deal discovery
- Brand store filters for popular FMCG companies
- Circular company logo filters for major FMCG brands
- Real product image URLs for branded FMCG products where available
- Search and sorting
- Minimum order quantity controls
- In-stock filtering
- ASCII-safe pricing text to avoid symbol encoding glitches
- Cart with GST and delivery calculation
- Purchase order dialog with business details
- Responsive layout for desktop and mobile

## Product image rule

Use real product pack images from official brand/product pages where possible. If an official asset is not available, use a verified product page from a trusted retailer. Feri packaging supplies may use the built-in branded fallback.

## Open the app

Open `index.html` directly in a browser, or run a local static server from this folder and visit:

```text
http://127.0.0.1:4173
```

## Files

- `index.html` - app layout
- `styles.css` - visual design and responsive styling
- `app.js` - product data, filtering, cart, and checkout behavior

## GitHub

This is a static web app. A GitHub repository only needs these files at the root:

- `index.html`
- `styles.css`
- `app.js`
